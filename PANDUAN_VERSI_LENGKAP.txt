OLSERA DATA CLEANER — FULL PREVIEW (Tahap 1-5, with safety limits)

1. Hentikan Streamlit lama (Ctrl+C).
2. Ekstrak ke FOLDER BARU.
3. Salin .env lama ke folder baru di samping app.py.
4. Jangan pindahkan atau hapus database di LOCALAPPDATA\OlseraDataCleaner.
5. PowerShell:
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   python -m pytest -q
   python -m streamlit run app.py

sebelum kita verifikasi perilaku endpoint update pada produk khusus pengujian.
